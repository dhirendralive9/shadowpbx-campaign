CSV with a header row, or a plain list of numbers
.csv or .txt — the format is detected from the first line, so you do not have to say which.
CSV — with a header row
phone,name,company,email
+4915112345678,Anna Weber,Weber GmbH,anna@weber.de
004915798765432,Jonas Klein,,
15551234567,Pat Lee,Lee Co,pat@lee.com
Only the phone column is required and it may be named phone, number, mobile, cell, tel or msisdn. If none of those match, the first column is used. first name and last name are joined when there is no name. A prefix or country_code column overrides this list's country code for that row.
Text — one number per line
+4915112345678
004915798765432
015112345678
9178 988 634
No header, no other columns. Spaces, dashes, brackets and dots are ignored. Numbers that are already international (+ or 00) are kept as they are; the rest get this list's country code , with a leading national 0 dropped.
Either way: duplicates already in this list are skipped, anything under 7 digits is counted invalid, and the import reports lines read, imported, duplicates and invalid.
